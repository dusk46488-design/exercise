2. **Key visualisation discoveries.** The group identified five findings that emerged from visualisations but were not apparent from tabular statistics:
   1. **Bimodality in spaced-condition retention.** The violin plot revealed a bimodal distribution (peaks near 25 and 75) — suggesting a mixture of responders and non-responders. The box plot completely concealed this.
   2. **Crossover interaction visible.** Condition-stratified box plots by test occasion made the hypothesised crossover immediately visible: daily above spaced at Occasion 1, reversed by Occasion 4.
   3. **Imputation spike in overlaid histograms.** The heuristic-imputation histogram showed a visible spike at the median — a structural artifact, not a genuine data feature.
   4. **Entropy comparison quantified.** The completeness comparison bar chart showed: filtering preserved 99.5% entropy, imputation reduced it by 3.75%, normalisation preserved exactly (affine).
   5. **Correlation structure validated.** The annotated correlation heatmap confirmed expected relationships: `test_occasion` ↔ `days_since_learning` at r = 0.93, `retention_score` ↔ `jol_prediction` at r = 0.89.

3. **Design principles review.** The group discussed the visualisation design principles applied:
   - Superposition over juxtaposition (Cleveland, 1993) — overlaid semi-transparent histograms rather than side-by-side panels
   - Raw data + summaries (Tukey, 1977) — box plots with individual data points and annotated statistics
   - Multi-faceted completeness diagnosis (Friendly, 2002) — three-panel layout: heatmap, corrgram, entropy bars

### Discussion Summary

1. **Visualisation plugin architecture.** Discussed the `VisualizationPlugin` ABC:
   ```python
   class VisualizationPlugin(ABC):
       @abstractmethod
       def plot(self, df: pd.DataFrame, output_path: str, **kwargs) -> None: ...
   ```
   Each plugin receives a DataFrame (or dict of DataFrames for history/comparison plots), renders the figure using matplotlib/seaborn, and saves to the specified path. Metadata (pipeline version, timestamp, column names, filter parameters) is embedded in the figure as text annotations.

2. **DatasetHistoryPlot design.** Discussed rendering overlaid semi-transparent histograms (α = 0.4) with KDE curves for comparing a single column across pipeline stages (raw → filtered → imputed → normalised). The superposition design (Cleveland, 1993) lets the viewer directly compare distributional shifts — the imputation spike at the median is immediately visible as a narrow peak in the heuristic-imputation curve that is absent from the raw, drop-filtered, and hot-deck curves.

3. **AggregatePlot: box vs. violin.** Discussed the trade-off:
   - **Box plot:** Shows median, IQR, and outlier fences — compact and familiar, but conceals multimodality
   - **Violin plot:** Shows full kernel density estimate — reveals bimodality, skew, and gaps, but less familiar to some audiences
   - **Decision:** Render both, overlaid (violin with inner box), plus annotated mean/median/IQR as text labels. This follows Hintze & Nelson (1998): violin plots as "box plot-density trace synergism."

4. **CompletenessPlot three-panel design.** Discussed the multi-faceted approach:
   - **Panel 1 (Missing-data heatmap):** Rows = observations, columns = variables — yellow = present, dark = missing. Reveals missingness patterns (scattered vs. clustered).
   - **Panel 2 (Correlation heatmap):** Annotated with |r| values, colour-scaled from −1 (blue) to +1 (red). Follows Friendly (2002) corrgram conventions.
   - **Panel 3 (Entropy bar chart):** One bar per column, ordered by entropy descending. Lower entropy = more concentrated distribution = potential imputation artifact.

5. **CompletenessComparisonPlot for cross-version comparison.** Discussed a grouped bar chart comparing entropy or missing rates across dataset versions (raw, drop-filtered, heuristic-imputed, hot-deck-imputed). This provides a principled, quantitative basis for choosing between imputation strategies — a decision often made by convention rather than evidence.

6. **Visualisation-to-discussion pipeline.** Discussed how each visualisation finding maps to the IMRaD Discussion:
   - Bimodality → suggests latent-class or quantile-regression approaches for future analysis
   - Crossover interaction → visually confirms H1b, connects to spacing-effect literature (Cepeda et al., 2006)
   - Imputation spike → methodological warning against single-imputation methods
   - Entropy comparison → quantitative justification for hot-deck over heuristic imputation
   - Correlation structure → validates the data-generation model against metamemory literature (Dunlosky & Metcalfe, 2009)
