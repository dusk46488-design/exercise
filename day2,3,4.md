## Day 2 Exercise – CLI & Git
### Individual Git Workflow
1. Create a local Git repository
   git init

2. Track file changes and commit Day 1 Research Stories
   git add research-stories.md
   git commit -m "Add Day 1 research stories"

3. Create and switch to a new branch
   git checkout -b feature/day2

4. Edit content, then stage and commit changes
   git add .
   git commit -m "Complete Day 2 CLI & Git practice"

5. Merge branch into main branch
   git checkout main
   git merge feature/day2

6. Push local repository to remote GitHub
   git remote add origin https://github.com/your-username/your-repo.git
   git push -u origin main

7. Clone the remote repository
   git clone https://github.com/your-username/your-repo.git

### Group Collaboration Workflow
1. Create a shared group repository on GitHub
2. Each member clones the repository
3. Each member creates a personal branch for editing
4. Members push changes to their respective branches
5. Merge branch updates into the main branch
6. Resolve conflicts and complete collaborative submission

### Python IPO Function (with docstring & comments)

def ipo_process(input_text):
    """
    IPO function: Input → Process → Output
    Input: raw text string
    Process: remove extra spaces and count length
    Output: cleaned text and length
    """
    # Remove extra spaces
    cleaned_text = input_text.strip()
    # Calculate character length
    text_length = len(cleaned_text)
    # Return final output
    return f"Processed Text: {cleaned_text}, Length: {text_length}"
